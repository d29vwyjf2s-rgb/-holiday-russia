# Праздники России 4.0

Новая версия Android-проекта календаря.

Что добавлено:
- полноценный экран календаря с цветовой подсветкой праздников и выходных;
- навигация по месяцам;
- выбор года;
- список праздников текущего месяца;
- карточка праздника;
- настройки;
- переключатель светлой/тёмной темы;
- разрешение уведомлений для Android 13+;
- механизм напоминаний через AlarmManager;
- работа без интернета;
- аккуратный интерфейс в стиле современного мобильного приложения.

Важно:
проект является исходниками для Android Studio. Для публикации в Google Play и для юридически точного производственного календаря потребуется отдельно поддерживать ежегодные переносы выходных и региональные праздники.
